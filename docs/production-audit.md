## What changed in this pass

1. **The graph has a real list view.** The Orbit / List switch exposes every child at a level as a native button with full labels, a live text filter over labels, paths and signatures, and the same drill and details actions. A level is no longer limited to what the canvas can draw.
2. **The MCP contract is published, not just described.** `GET /api/mcp/schema` and `docs/mcp-tools.json` are generated from the executable catalog. `tests/mcp-contract.test.ts` fails if the committed schema and the served tools diverge, and live Playwright checks the 11 names, read-only annotations and input schemas.
3. **Public claims are guarded in CI.** `bun run check:claims` checks the README size, edge count, cycle count, SQL resource count, service count, all 11 tool names, zero-width spaces and em dashes. A stale number now fails the build instead of reaching a visitor.
4. **The unresolved-import proof now proves the healer.** The scenario imports a real sibling module through a folder that does not exist, so the verified result is a genuine import rewrite rather than a refusal to heal a self-import.
5. **The snapshot and README are relocked.** The committed analysis is 220 files, 41,216 LOC and 485 internal edges, and every public number matches it.

## Where this release still falls short

1. **Live model output was not observed against the platform provider.** The configured Nara model still answers "The requested model is not available." Stage 2 completes through the labeled deterministic proposal derived from the real file, which is honest, grounded and browser-verified, but it is not evidence that the external model produced the file. A working Cloudflare Workers AI, Gemini or OpenRouter key in API Settings exercises the model path.
2. **The GLSL shader could not execute in this environment.** Chromium here exposes no WebGL2 context, so the tested path is the CSS fallback. The canvas mount, accent state and computed background change are verified; the GPU shader is not.
3. **The orbit sector selector was not exercised.** The live repository has no hub wider than 24 children, so the threshold path remains unit-covered by construction and unobserved live.
4. **The clipboard action on the context pack was not asserted.** The button renders and the payload is deterministic, but headless clipboard permissions were not granted in the audit.
5. **Grounded generation remains a single-file contract.** Files above 20,000 characters are refused instead of truncated, and multi-file changes still belong to the reviewed PR route.
6. **The self-index carries no git history.** Memory Q&A reports commit and PR history as absent rather than inventing it.

No mock, seeded or sampled values were introduced. Every count, path, line, verdict and timing figure here comes from the live analysis payload, the real browser run, or the commands listed above.
